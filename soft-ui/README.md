# Soft UI

独立的新拟态界面示例，用于和 `raster-ui` 的像素 UI 区分。本目录不修改或覆盖原仓库文件。

打开 `index.html` 即可预览浅色和深色两套表面。设计原则是控件和底板保持同一材质，用左上高光、右下暗影表达凸起，用内阴影表达凹陷和选中态；同时用文字对比、颜色和描边保证可读性与键盘焦点可见。

本版视觉进一步收敛为 Precision Neumorphism：采用偏暖雾灰背景、低饱和靛紫和腮红强调色，缩短阴影距离，统一圆角与控件高度，并用细边缘高光、内凹状态和更清晰的文字对比表现高级触感。深色模式同步使用更克制的石墨色层次。

页面顶部的材质组件库复用根目录 `material-ui.js` 与 `material-ui.css`，提供基础控件、表单、卡片、列表、对话框、通知、入场反馈和柔和光晕演示。动效由材质层独立驱动，使用平滑的缓动、缩放、亮度和泛光过渡，并尊重“减少动态效果”设置。

页面顶部的材质组件库已扩展为 v0.2 完整目录：15 个章节、分组导航、组件搜索、基础规则、14 个图标、按钮与加载状态、完整表单语义、复选/单选/开关、分段筛选、页签、导航、卡片与列表、状态提示、空态/骨架、弹窗/通知、响应式组合、接入 API 和材质动效实验室。每个章节都提供可复制的 HTML 用法；动效继续由材质层独立驱动，并尊重系统减少动态设置。
