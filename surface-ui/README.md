# Surface UI

这是独立于 `raster-ui` 的可切换皮肤结构。玻璃页现在以参考图为目标做成两种完整材质：`柔雾磨砂` 对应奶油白、薄荷和腮红色的低饱和漫反射；`液态彩光` 对应深色背景、彩色折射和更强的发光投影。页面结构和交互共用一套组件语义，材质、阴影、颜色和模糊效果拆成独立主题文件，互不污染，也不覆盖原像素 UI。

- `base.css`：布局、字号、组件结构、交互状态和焦点可见性。
- `themes/neumorphic.css`：新拟态皮肤。
- `themes/glass.css`：玻璃拟态皮肤。
- `index.html`：同一套组件结构下的皮肤切换示例，以及两套玻璃材质的参考组件画板。
- `ui.js` 内联在页面底部：仅处理切换、分段选择、开关等交互。

打开 `index.html` 即可在顶部切换新拟态、柔雾磨砂和液态彩光。新增皮肤时，只需在 `themes/` 下再加一个独立 CSS 文件，并按同一套组件语义覆盖对应变量。

页面下方的材质组件库复用根目录 `material-ui.js` 与 `material-ui.css`，提供基础控件、表单、卡片、列表、对话框、通知、入场反馈和柔和光晕演示。动效由材质层独立驱动，玻璃主题只替换表面变量，不改变组件语义。

页面下方的材质组件库已同步扩展为 v0.2 完整目录：分组导航、组件搜索、基础规则、14 个图标、按钮与加载状态、完整表单语义、复选/单选/开关、分段筛选、页签、导航、卡片与列表、状态提示、空态/骨架、弹窗/通知、响应式组合、接入 API 和材质动效实验室。每个章节都提供可复制的 HTML 用法；玻璃主题只替换表面变量，不改组件语义和可访问行为。
