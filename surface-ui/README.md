# Surface UI

这是独立于 `raster-ui` 的可切换皮肤结构。页面结构和交互共用一套组件语义，材质、阴影、颜色和模糊效果拆成独立主题文件，互不污染，也不覆盖原像素 UI。

- `base.css`：布局、字号、组件结构、交互状态和焦点可见性。
- `themes/neumorphic.css`：新拟态皮肤。
- `themes/glass.css`：玻璃拟态皮肤。
- `index.html`：同一套组件结构下的皮肤切换示例。
- `ui.js` 内联在页面底部：仅处理切换、分段选择、开关等交互。

打开 `index.html` 即可在顶部切换两种风格。新增皮肤时，只需在 `themes/` 下再加一个独立 CSS 文件，并按同一套组件语义覆盖对应变量。
