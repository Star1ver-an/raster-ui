PUBLISH YOUR COLLECTION

把设计，放到一个可分享的地址。

这是一份纯静态组件库。管理页与三套文档使用相对路径，可以作为 GitHub Pages 项目站点展示。

  1. 01

    提交完整项目

    将根目录管理页、共享资源和三套组件库一起提交到仓库。

  2. 02

    启用 GitHub Pages

    打开仓库 Settings → Pages，将 Source 设为 GitHub Actions。

  3. 03

    运行部署工作流

    推送到 master，或在 Actions 中手动运行 Deploy UI Collection。工作流只发布构建后的静态文件。

收藏和视图偏好只保存在当前浏览器。在线管理页用于浏览与整理，不需要账户或服务器。
