# 五种风格的设计学习与组件化

本次将极简主义、Material 表现力设计、流动玻璃、新粗野主义、沉浸式 3D 转化为五套长期保存的 Web 组件库。每套均有 18 章、两种主题、设计变量、代码用法、可操作工作台和动效实验室。它们与原有 Raster、Soft、Surface 一起进入 UI Collection，当前共 8 套、144 章、15 种主题。

## 学习依据与转化方法

| 参考方向 | 主要学习来源 | 本项目的独立实现 |
| --- | --- | --- |
| 极简主义 | [Apple AirPods Pro 产品页](https://www.apple.com/airpods-pro/)的产品优先、视觉比例与阅读节奏 | Minimal UI，强调取舍、留白和局部连续性 |
| Material | [Google Material 3 Expressive 官方研究](https://design.google/library/expressive-material-design-google-research)的色彩、形状、尺寸、运动与容器分组 | Expressive UI，强调语义角色、形状反馈和分组节奏 |
| 玻璃质感 | [Apple Liquid Glass 官方介绍](https://www.apple.com/newsroom/2025/06/apple-introduces-a-delightful-and-elegant-new-software-design/)的功能层、环境融合与动态变化 | Liquid UI，以 CSS 透明、模糊与边缘高光近似光学感 |
| 新粗野主义 | [Gumroad 官网](https://gumroad.com/)的图形语言、清晰轮廓与品牌识别 | Brutal UI，强调明确边界、硬投影和果断操作反馈 |
| 沉浸式 3D | [Lusion 主创案例](https://www.thenerodesign.com/project/lusion)的设计与技术协作，以及[原站](https://lusion.co/)的空间体验 | Spatial UI，用轻量 CSS 3D、局部视角与可逆滚动表达空间 |

上表中的风格归纳和下面的参数均是本项目的设计分析与决策。参考用于理解原则，没有复制品牌标志、产品图片、专有着色器、WebGL 物理引擎或系统级实时折射实现。页面运行不依赖外站。

## Minimal UI

精髓是优先级与比例。留白要能区分内容组，字阶要能引导阅读，一屏要有明确主体。删除冗余之后仍然需要清楚的边界、可见焦点、足够对比和明确操作。

组件采用中性底色、单一绿色强调、细分隔线和克制的圆角。页签以底线建立选择关系，正文优先稳定。动画以短距离入场、局部显隐和同一预览展开为主；用户不需要等待一次演出才能开始操作。

| 动效 | 触发与过程 | 终态与打断 |
| --- | --- | --- |
| 入场 | 内容就绪后 12px → 0，260ms | 显示完整内容；重播替换旧动画 |
| 操作反馈 | 点击后小幅缩放，140ms | 操作先成立，反馈不改变业务数据 |
| 共享表面 | 点击展开同一对象，FLIP 维持起终点关系 | 展开状态立即更新，可反向收起 |
| 滚动展示 | 区间进度控制轻微位移与缩放 | 反向可退回，减少动态直接完整呈现 |

## Expressive UI

精髓是用系统组织表现力。强调色承担主要操作，柔和容器承担内容分组，圆角和形状变化说明选择与状态。鲜艳并不是让每个控件都获得同等强调。

组件采用丁香与深紫主题，少量绿色容器形成节奏；按钮与筛选具有可识别的形状。按压反馈局部伸缩，滚动演示将形状与缩放连续映射到进度。原生列表、标签和导航模式保持熟悉。

按压反馈 180ms，内容入场 320ms，退出 180ms。形状和组内节奏用于表达关系，不将任意弹跳应用到所有控件。此库是独立 Web 实践，不等同于官方 Material 组件包。

## Liquid UI

精髓是前后关系。内容层拥有清晰文字和稳定结构，功能层以透光表面浮在其上，顶部高光交代边缘。背景参与着色但不能妨碍文字辨认。

相较原有 Surface UI 的材质探索，此库重点展示功能表面的连续展开、浮动导航与裁剪揭示。晨光和暮色主题都保留受控的不透明内容底色；透明感集中到适当的功能表面。

反馈 170ms、入场 300ms、退出 190ms。共享表面保持同一对象，滚动演示使用局部裁剪而非大面积动态模糊。CSS 无模糊能力时，表面的底色和边框仍然提供基本可读性。

## Brutal UI

精髓是直接的结构与强烈的识别。黑色轮廓、硬投影、明亮色块和大胆排版必须形成稳定语法。按钮投影交代凸起，按压位移交代反馈，正文与表单保持平实易读。

组件采用奶油撞色和黑底霓色，主色粉色与局部黄绿图形形成对比。按钮按下移动 4px 并收回硬投影；卡片选中用明确轮廓和 aria-pressed 表达。

按压 100ms、入场 200ms、退出 120ms。滚动演示使用明确的横向剪切。高频操作短促而果断，版式边界不随悬停改变；不使用柔焦、发光或弹性拖尾来混淆材质。

## Spatial UI

精髓是输入与空间变化之间的关系。场景应有初态、可停留的过程和终态。文字与操作保持稳定平面，空间承担展示，普通内容导航不被场景接管。

组件采用日光与深空展厅，主场景由六面立方体组成，具有真实的 CSS 3D 深度。精细指针只改变局部视角，离开后归位；滚动区和滑杆控制同一条可逆空间过程，触摸设备不必依赖悬停。

入场 420ms，反馈 180ms，退出 220ms。无无限自转；减少动态模式停止倾斜和深度变化并显示静态场景。该库适合轻量空间界面，复杂实时物理、模型资产和 WebGL 另行设计。

## 资源与维护边界

- 五套目录分别是 `minimal-ui`、`expressive-ui`、`liquid-ui`、`brutal-ui`、`spatial-ui`。
- 每套的 CSS 与 `tokens.json` 定义自己的颜色、边界和时长；`design-kit/core.css` 与 `core.js` 提供共享组件和交互。
- `design-kit/catalog.js`、`styles.js`、`docs.js`、`docs.css` 只服务文档与演示，不是业务产品必需依赖。
- 示例数据以风格独立的 localStorage 键保存。复制代码、下载 Tokens、相对路径接入均可离线复用。
- 改动核心运行层时运行 `design-kit/tests.html`；改动风格时核对两种主题、窄屏、焦点和减少动态模式。
- 打包脚本收录八套库与共享资源，ZIP 可用于后续开发或静态部署。

## 本次验证记录

2026年10月19日，在本机浏览器完成五套库的 145 项交互检查，全部通过；包括 320px 和 390px 无页面横向溢出、嵌套初始化、表单纠错、模态竞态、减少动态、项目保存与归档撤销。十种主题均检查实际渲染；基础正文、次要文字与主按钮的预设配色对比均不低于 4.5:1，透明叠层仍应在后续业务背景中复核。集合分类、搜索和主题链接已验证。静态构建会检查本地资源引用并打包全部组件资源。
