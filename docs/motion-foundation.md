# UI Collection 动效设计基石

本项目以用户提供的《你应该知道的网页交互术语 01》作为动效设计参考。动效需要说明操作因果、维持内容连续性、组织浏览节奏，并表达 Raster、Soft、Surface 各自的材质。设计和评审时，先确定动效的作用与触发方式，再选择视觉表现。

适用范围：组件库管理页、三套组件目录、组合工作台、动效实验室，以及后续新增展示页面。本文确立后续设计基准；下文标为“设计起点”或“待扩展”的内容不代表已有功能。

## 本项目的设计原则

1. **建立因果。** 按下回应操作，加载说明等待，转场交代去向，完成反馈确认结果。每个动效应能说明它帮助用户理解什么。
2. **保持连续。** 明确元素从哪里来、到哪里去、与原内容是什么关系。展开、收起和返回的方向应一致，必要时保持共享元素。
3. **编排注意力。** 同一时刻突出一个主动作，其余动作辅助它；标题、内容、操作按阅读顺序出现。避免让所有卡片同时争夺注意力。
4. **表达材质。** 三套库共用交互语义，各自采用适合材质的运动方式；像素的落格、实体表面的按压、玻璃的层次变化应可辨认。
5. **让用户控制进度。** 普通交互及时响应；滚动叙事允许停留、回看和跳过。新操作可以打断旧动画，不能排队累积。
6. **静态状态同样完整。** 减少动态效果、触摸设备和脚本失败时，内容、操作、结果仍然可理解。动画不能成为阅读内容的唯一入口。

## 按场景决定动效强度

| 层级 | 使用位置 | 默认设计方向 |
| --- | --- | --- |
| 基础反馈 | 按钮、开关、表单、筛选、页签、加载、弹窗和通知 | 小范围、及时、可打断；状态先成立，动画帮助辨认变化 |
| 内容组织 | 目录区块、结果列表、预览切换、卡片到详情 | 有层次的入场、局部交错、共享元素、轻量遮罩；保持检索与阅读效率 |
| 展示叙事 | 首屏、材质介绍、动效实验室、独立演示 | 可以使用视差、滚动驱动文字与图片、分屏、横向章节、3D 与粒子；每段有清晰展示目的 |

组件文档以浏览和复制用法为主，目录跳转不插入整页演出。展示区应大胆表达材质与空间，丰富动效集中到有明确主题的区域。全屏分段、横向叙事和长距离滚动控制均作为独立演示能力，保持普通文档的纵向浏览路径。

## 核心效果的使用规则

### 加载与入场

- 真实资源或业务请求决定加载结束，不为展示 Logo 或凑满时长人为等待。无法测量时使用不确定进度，不展示虚构百分比。
- 加载区预留尺寸，先呈现可用结构；结果到达后自然衔接内容。后续局部加载优先在局部表达。
- 一次入场先交代主体，再展开辅助内容与操作。搜索输入、每次筛选和回到已浏览章节不重复整段首屏演出。
- “首次加载”描述等待过程，“入场”描述内容出现；可以衔接，但不要把同一段等待重复执行两遍。

### 转场与共享元素

- 页签、预览、弹窗优先局部衔接。确有独立页面关系时再设计页面转场。
- 同一对象从卡片进入详情时，可以延续封面、标题或材质样本；预先确定起点、终点和返回状态。
- 页面 URL、浏览器返回、滚动位置与焦点仍然正确。共享元素匹配失败时直接呈现目标内容。
- 遮罩可以组织先后关系，但不能遮住错误信息或在内容就绪后继续阻挡操作。

### 滚动触发与滚动驱动

| 机制 | 控制方式 | 适合用途 | 反向滚动 |
| --- | --- | --- | --- |
| 滚动触发入场 | 元素进入约定区域后，按固定时长播放 | 章节标题、内容组、列表首次出现 | 默认保留完成态，避免边界来回触发 |
| 滚动驱动 | 区间内的滚动进度映射到动画进度 | 材质变化、文字重组、图像展开、空间叙事 | 按同一映射退回，停止滚动即保持对应状态 |
| 视差 | 多个层以不同幅度随滚动移动 | 展示背景、预览场景、前后景 | 各层沿同一规则恢复，正文与操作保持稳定 |

- 每个滚动驱动场景写清开始位置、结束位置、进度映射与退出后的版式；用户快速滚过时也必须到达正确终态。
- 普通文档保留原生滚动。需要惯性滚动的独立展示另行设计，确保锚点、键盘、触摸与返回定位有效。
- 固定场景与横向章节要有明确的开始和结束，不把用户困在长距离空滚中。窄屏可改为普通纵向内容。
- 图片遮罩和大标题可以承担展示重点；表单说明、代码、正文不逐字拆散，完整语义文本应始终可访问。

### 操作反馈与悬停

悬停、按压、成功和错误反馈是本项目对组件交互的配套规则，不将它们列为视频主线的独立章节。

- Hover 表示可操作，Pressed 表示已响应，Selected 表示持续选择；三个状态不能混淆。
- Hover 附加预览需有键盘与触摸等价入口。鼠标跟随和磁吸如用于实验室，仅增强视觉提示，保持实际点击区域稳定。
- 成功先落实结果，再播放局部强调；失败保留内容、说明原因与恢复入口。粒子和光晕用于有意义的完成时刻。

## 三套材质的运动语言

| 材质 | 基础节奏 | 视频手法的项目化表达 | 约束 |
| --- | --- | --- | --- |
| Raster UI | 整数位移、阶梯缓动、短促落格 | 分步入场、格点遮罩、颗粒归位、可见起终点的归档 | 保持已有整数格点与像素粒子规则；核心组件不用连续弹簧、模糊光晕或整页转场 |
| Soft UI | 轻微下沉与复位，表面明暗随状态变化 | 实体表面的按压、轻量入场、同一表面展开、完成时局部柔光 | 保持既定光源与实体厚度；阴影变化不承担唯一状态说明 |
| Surface UI | 层之间平滑衔接，透明表面的前后关系 | 玻璃面板展开、裁剪揭示、受控视差、共享表面、局部高光变化 | 保持文字对比与背景稳定；避免大面积持续模糊变化和正文漂移 |

同一个“保存成功”在三套库都必须有明确结果；Raster 可以颗粒归位，Soft 可以局部按压后确认，Surface 可以高光短暂收束。它们表达相同语义，采用各自材质的动作。

## 时长与节奏基准

以下参数分为已有实现和后续设计起点，均不是视频给出的数值。已有组件优先复用自身变量，新增动效需按实际体验调整。

| 场景 | Raster 已有基准 | Soft / Surface 已有示例或设计起点 |
| --- | --- | --- |
| 按下反馈 | `--rg-motion-press: 80ms`，下沉 2px | 已有 `materialFeedback` 为 170ms、位移 1px |
| 选择反馈 | `--rg-motion-select: 160ms` | 设计起点 160–220ms |
| 入场 | `--rg-motion-enter: 200ms`，弹窗 12 → 8 → 4 → 0px | 已有入场示例标注 160–200ms；复杂表面展开设计起点 240–320ms |
| 退出 | `--rg-motion-exit: 120ms` | 已有通知退场 180ms、弹窗关闭 220ms |
| 完成反馈 | `--rg-motion-confirm: 240ms` | 已有局部 Bloom 为 560ms；完成状态无需等待光晕播完 |
| 列表交错 | 已有间隔 24ms、最大延迟 96ms、最多 12 项 | 设计起点间隔 30–40ms、最大延迟 120ms；长列表后续内容直接出现 |
| 展示型效果 | 已有可选粒子 720 / 820 / 880ms | 展示按叙事决定节奏；滚动驱动以滚动区间控制，不硬套固定时长 |

Raster 继续使用 steps 与整数关键帧。Soft / Surface 入场可沿用平滑减速、退出采用较短的加速；涉及相同对象的转场优先保持路径和速度连续。跨页面共用语义与节奏层级，不强行统一所有材质的缓动曲线。

## 减少动态效果与实现边界

- 系统减少动态效果和项目内减少动态偏好均须生效；切换时取消运行中的位移、视差、粒子、惯性和持续装饰动画，直接呈现对应可用状态。
- 减少动态时保留加载文字、选中态、成功与错误说明；滚动叙事恢复正常内容顺序，避免内容仍被固定或裁切。
- 默认内容可见。仅在动画能力成功初始化后设置入场初态，避免脚本失败造成整页空白。
- 位移和显隐优先使用 transform / opacity。裁剪、阴影、透明度、3D 各按实际场景评估，避免每帧改动布局或对整页施加昂贵滤镜。
- 可选展示能力按需启用；不因参考视频引入外部字体、第三方动画依赖、自动播放视频或网络服务。当前项目的静态、无外部运行依赖方式继续适用。
- 重复触发、快速返回、窗口缩放、动态内容插入和销毁时，要替换旧动画并清理观察器、监听器和临时节点。

## 新增动效的设计记录与验收

每个新增效果写清：**目的 → 触发 → 主体 → 路径或属性 → 时长或滚动区间 → 终态 → 打断行为 → 减少动态替代**。简单按钮可用一句话记录，复杂滚动叙事需逐段描述。

例如：“Surface 材质样本首次进入展示区后，玻璃面板沿固定边展开，240ms 到达可读终态；离开视口保留终态，快速切换样本取消旧动画，减少动态时直接显示完整面板。”这是后续设计示例，不是现有功能描述。

评审至少检查以下结果：

- 能解释动效对应的因果、内容关系或展示主题，三套材质的动作符合各自规则。
- 初态、过程、终态可理解；快速点击、反向滚动和中断后状态正确，旧动画不会覆盖新操作。
- 键盘、触摸、目录锚点、浏览器返回和焦点恢复有效；减少动态时没有隐藏内容或滚动陷阱。
- 首屏可及时阅读；动态内容不造成无意跳动，滚动和输入过程没有明显停顿。
- 演示区能独立重播和比较；示例能力与产品默认行为区分清楚。
